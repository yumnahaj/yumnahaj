# مُرشد

> **من سيرتك إلى تدريبك بخطة واضحة**

نموذج أولي تفاعلي لتطبيق ويب عربي يساعد طلاب الجامعات في السعودية على الاستعداد لفرصة **تدريب تعاوني محددة**، لا على اختيار مسار وظيفي عام.

يأخذ مُرشد ثلاثة مدخلات — بيانات الطالب، ونص السيرة الذاتية، ونص إعلان التدريب — ويخرج بـ:

- **درجة تطابق** مع تفصيل كامل لطريقة حسابها.
- **فجوة المهارات**: المستوى الحالي مقابل المطلوب، مع الدليل الموجود في السيرة لكل مهارة.
- **خطة استعداد** من أربعة أسابيع بمهام قصيرة قابلة للتنفيذ.
- **تحسينات مخصصة للسيرة** بصياغات «قبل/بعد» قابلة للنسخ والتطبيق.

> **تنويه مهم:** ما يعرضه مُرشد هو **درجة تطابق** و**جاهزية تقديم**، وليست «احتمالية قبول». الرقم تقديري يساعدك على ترتيب أولويات استعدادك، وليس قرارًا صادرًا عن جهة توظيف ولا ضمان قبول.

## التشغيل

المتطلبات: Node.js 18 أو أحدث.

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء الإنتاج (tsc + vite)
npm run preview  # معاينة ناتج البناء
```

لا يحتاج المشروع إلى backend، ولا قاعدة بيانات، ولا مفتاح API، ولا أي خدمة مدفوعة. كل شيء يعمل داخل المتصفح.

## تجربة السيناريو التجريبي

أسرع طريقة لرؤية المنتج كاملًا خلال أقل من دقيقتين:

1. من صفحة البداية اضغط **«جرّب ببيانات تجريبية»**.
2. تظهر شاشة التحليل بمراحلها الأربع، ثم تنتقل تلقائيًا إلى لوحة التحكم.
3. لوحة التحكم تعرض **درجة تطابق 77٪** لفرصة «متدرب تحليل بيانات».
4. افتح **فجوة المهارات** وشاهد فجوة **Power BI** (35٪ مقابل 75٪ مطلوبة).
5. انتقل إلى **خطة الاستعداد** لرؤية الأسابيع الأربعة.
6. علّم مهمة واحدة كمكتملة وراقب **نسبة الإنجاز** تتغير فورًا (وتُحفظ في المتصفح).
7. افتح **تحسين السيرة**، واضغط **«نسخ الصياغة»** أو **«تطبيق الاقتراح»** وشاهد المعاينة تتحدث.

الشخصية التجريبية: **نورة خالد** — طالبة نظم معلومات، التخرج 2027، الرياض، المعدل 4.3 من 5. الفرصة: **متدرب تحليل بيانات** لدى **شركة نمو الرقمية** (جهة افتراضية، موسومة بشارة «بيانات تجريبية»).

يمكنك أيضًا سلوك المسار اليدوي عبر **«ابدأ تحليل ملفي»**، مع زرّي **«استخدم سيرة تجريبية»** و**«استخدم إعلانًا تجريبيًا»** لتعبئة الحقول بسرعة.

## ما هو حقيقي في النموذج وما هو تجريبي

### يعمل فعليًا

- **محرك التحليل** (`src/lib/analyze.ts`): مطابقة نصية محلية بين نص السيرة ونص الإعلان، مع توحيد الأسماء العربية والإنجليزية للمهارة الواحدة.
- **تطبيع النص العربي**: إزالة التشكيل والتطويل، وتوحيد الهمزات والألف المقصورة والتاء المربوطة قبل المطابقة.
- **تصنيف المتطلبات** إلى أساسية ومفضلة اعتمادًا على عناوين الأقسام داخل الإعلان (مثل «المهارات المفضلة:») وعلى عبارات مثل «ميزة إضافية».
- **حساب الدرجة** بأوزانها الخمسة، واستخراج الأدلة من السيرة لكل مهارة.
- **توليد الخطة** من أكبر فجوتين، وحفظ حالة كل مهمة في `localStorage`.
- **جاهزية السيرة** والكلمات المفتاحية الناقصة، وتطبيق الاقتراحات على المعاينة.
- **الحالات الفارغة والناقصة**: تنبيه عند قصر نص السيرة، وتنبيه عند عدم استخراج متطلبات كافية من الإعلان.

### تجريبي أو غير مفعّل

- **لا يوجد نموذج ذكاء اصطناعي ولا طلب شبكة.** التحليل مطابقة نصية محلية بالكامل.
- **لا تُقرأ ملفات PDF وDOCX.** عند رفع ملف نعرض اسمه فقط ونطلب لصق النص؛ لا ندّعي قراءته.
- **الفرص والجهات تجريبية** وموسومة بشارة «بيانات تجريبية»، وغير مرتبطة بأي جهة حقيقية.
- **مستويات المهارات في السيناريو التجريبي** (`DEMO_SKILL_LEVELS` في `src/data/demo.ts`) مُقدَّرة مسبقًا لتثبيت أرقام العرض. أما الإدخال الحقيقي فتُحسب مستوياته من نص السيرة عبر المحرك، وهذا موضّح داخل قسم «كيف حسبنا النتيجة؟».

## طريقة حساب درجة التطابق

الدرجة مجموع خمسة مكوّنات موزونة:

| المكوّن | الوزن | كيف يُحسب |
| --- | --- | --- |
| المهارات الأساسية | 45٪ | متوسط `min(1, الحالي ÷ المطلوب)` لكل مهارة أساسية في الإعلان |
| المهارات المفضلة | 20٪ | المتوسط نفسه، مع خفض السقف المطلوب خمس نقاط لأنها ليست شرطًا |
| أدلة المشاريع والخبرة | 15٪ | وجود مشروع، ذكر الأدوات داخله، وجود أرقام للأثر، وجود رابط لمعرض الأعمال |
| جاهزية السيرة | 10٪ | 100 ناقص خصومات: الكلمات المفتاحية الناقصة، غياب الأرقام، غياب قسم المشاريع أو المهارات |
| توافق الشروط العامة | 10٪ | تطابق المدينة، المرحلة الدراسية، سنة التخرج، وتحديد موعد بدء التدريب في الإعلان |

**مستوى المهارة** يُقدَّر من قوة الدليل في السيرة: الذكر المجرد في قائمة المهارات يعطي أساسًا منخفضًا، ويرتفع عند ورود المهارة داخل سياق مشروع أو خبرة، أو دعمها بدورة، أو تكرارها، أو اقترانها برقم أو بوصف إجادة. وإذا غابت المهارة تمامًا وتوفرت مهارة قريبة منها، تُمنح نقطة انطلاق جزئية بدل الصفر.

**حالة المهارة** تُشتق من نسبة الحالي إلى المطلوب: 100٪ فأعلى «متطابق»، و70٪ فأعلى «يحتاج تحسين»، وما دون ذلك «فجوة عالية».

إذا لم يذكر الإعلان مهارات مفضلة، يُضاف وزنها إلى المهارات الأساسية بدل منحه مجانًا. وإذا تعذّر استخراج أي متطلبات، تسقط نقاط المهارات كلها وتظهر النتيجة منخفضة مع تنبيه واضح، حتى لا يعطي النموذج درجة عالية بلا أساس.

## الربط المستقبلي بمحرك AI

الدالة `analyzeProfile(input, options)` نقطة استبدال واحدة. توقيعها يقبل `AnalysisInput` ويعيد `AnalysisResult`، لذا يكفي استبدال جسمها بطلب شبكة دون لمس أي مكوّن واجهة:

```ts
// الحالي: محلي بالكامل
const result = analyzeProfile(input);

// لاحقًا: نفس المدخلات ونفس المخرجات
const result = await fetch('/api/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(input),
}).then((response) => response.json() as Promise<AnalysisResult>);
```

المعمارية المقترحة للخدمة:

1. **استخراج نص السيرة** من PDF أو DOCX على الخادم.
2. **تحويل الإعلان إلى بيانات منظمة**: مهارات أساسية ومفضلة، ومستوى مطلوب لكل مهارة.
3. **توحيد أسماء المهارات** العربية والإنجليزية في معرّف واحد (توسعة لـ `SKILL_LIBRARY`).
4. **مقارنة المتطلبات بأدلة الطالب** مع إرجاع الاقتباس الداعم لكل مهارة، لا درجة مجردة.
5. **توليد خطة تطوير** مرتبطة بأكبر فجوتين وبالوقت المتاح للطالب.

يُفضَّل أن يبقى شرح الدرجة (`components` و`strengths` و`weaknesses`) جزءًا من استجابة الخدمة، حتى يظل المستخدم قادرًا على فهم سبب النتيجة لا الرقم وحده.

## الخصوصية

- كل البيانات تُحفظ في `localStorage` داخل متصفح المستخدم فقط، ولا تُرسل إلى أي خادم.
- زر **«إعادة ضبط البيانات»** يمسح كل شيء نهائيًا.
- لا يطلب النموذج رقم الهوية ولا رقم الجوال ولا العنوان.

---

## إمكانية الوصول واللغة

- اتجاه **RTL** كامل، وجميع النصوص والأزرار بالعربية، مع إبقاء أسماء التقنيات بالإنجليزية (SQL، Python، Power BI).
- حالة تركيز ظاهرة للتنقل بلوحة المفاتيح، ورابط «تخطَّ إلى المحتوى».
- كل حقل مرتبط بـ `label`، ورسائل الأخطاء مباشرة ومقترنة بـ `role="alert"`.
- حالة المهارة لا تعتمد على اللون وحده: لون + أيقونة + نص.
- احترام `prefers-reduced-motion`، وأنماط طباعة مخصصة للخطة والسيرة.
